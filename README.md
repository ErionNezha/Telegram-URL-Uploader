# Telegram URL Uploader Bot

Bot Telegram që shkarkon file nga URL dhe i ngarkon në chat (pyrogram) — me progres shkarkimi.

`Python` `pyrogram` `Telegram`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Telegram-URL-Uploader/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Vendos kredencialet, `pip install -r requirements.txt`, pastaj `python main.py`.
